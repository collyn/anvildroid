Images

Download and import Android images for your runtimes.

Image library

Choose a folder containing system.img and vendor.img directly, or a ZIP containing both files for Waydroid x86_64, Android SDK 33+ (ext4, EROFS, SquashFS or Android sparse). Sparse images are expanded automatically. Newer Android support is experimental: Prepare checks required Waydroid components; boot and desktop controls still depend on the build. Image import creates an independent runtime; it does not replace Default runtime. Use images from a source you trust. Custom Android builds may not support AnvilDroid desktop controls or ARM translation.
