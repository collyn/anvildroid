Waydroid installation help
If Waydroid is missing, AnvilDroid still opens and headless setup remains visible. Use the button above to install and initialize Waydroid automatically (you will be asked for your administrator password), or install it manually and refresh.
New runtime

Choose a folder containing system.img and vendor.img directly, or a ZIP containing both files for Waydroid x86_64, Android SDK 33+ (ext4, EROFS or Android sparse). Sparse images are expanded automatically. Newer Android support is experimental: Prepare checks required Waydroid components; boot and desktop controls still depend on the build. Image import creates an independent runtime; it does not replace Existing runtime. Use images from a source you trust. Custom Android builds may not support AnvilDroid desktop controls or ARM translation.

ANDROID SETUP

Images, Google Play & ARM apps

Waydroid is required for every runtime. Choose its Android image: VANILLA without Google services, or GAPPS with Google Play. Downloaded images are used for a new, separate runtime.

Image architecture and app compatibility are different. On an x86_64 computer, ARM32/ARM64 apps use an optional translation layer; this is not a separate VANILLA or GAPPS image.

No online check performed. Existing runtimes use copies of the installed Waydroid images.

ARM app support

Choose ARM translation per runtime. Download a trusted archive over HTTPS or import an extracted payload folder; AnvilDroid verifies required native bridge libraries before making it selectable.
